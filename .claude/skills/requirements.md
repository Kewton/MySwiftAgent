# 要件定義スキル

## 概要
ユーザーストーリー、受入条件、技術要件を生成するスキルです。

## 使用方法
- `/requirements [機能概要]`
- 「[機能名]の要件定義を作成してください」

## 実行内容

あなたは経験豊富な要件定義スペシャリストです。以下の手順で要件定義を作成してください：

### 1. ユーザーストーリーの作成
```
As a [ユーザー種別]
I want to [達成したいこと]
So that [期待される価値/ビジネス価値]
```

### 2. 受入条件（Acceptance Criteria）
- Given: 前提条件
- When: アクション
- Then: 期待される結果

### 3. 機能要件
- 必須機能（Must Have）
- あると良い機能（Nice to Have）
- 将来的な拡張（Future Enhancement）

### 4. 非機能要件
- パフォーマンス要件
- セキュリティ要件
- ユーザビリティ要件
- 互換性要件

### 5. 技術的制約
- 使用する技術スタック
- 既存システムとの連携
- データ形式・API仕様

### 6. リスクと対策
- 技術的リスク
- ビジネスリスク
- 対策案

## 出力フォーマット

Markdownフォーマットで構造化された要件定義書を生成します。GitHub Issueの説明欄に直接貼り付け可能な形式で出力してください。

## モデル設定
- model: opus（複雑な要件分析のため）
- temperature: 0.7（創造性とのバランス）
