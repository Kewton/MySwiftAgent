## 5. 改善提案

### 推奨改善（承認後も検討推奨）

1. **[中優先度] タイムアウト戦略の検証追加**
   - 問題: DP-12のフィードバックタイムアウト戦略が直接検証されていない
   - 改善案: TC-013にタイムアウト値の検証を追加
   ```typescript
   // TC-013に追加
   expect(mockLLMClient.calls[0].timeout).toBe(30000);  // initial
   expect(mockLLMClient.calls[1].timeout).toBe(45000);  // retry1
   expect(mockLLMClient.calls[2].timeout).toBe(60000);  // retry2
   ```
   - 対象: TC-013

2. **[低優先度] secret_key非開示の明示的検証**
   - 問題: TC-019で_internal除外は検証しているが、secret_keyの非開示は暗黙的
   - 改善案: TC-019に明示的なアサーション追加
   ```typescript
   // TC-019に追加
   expect(output).not.toContain('secret_key');
   expect(output).not.toContain('api_key');
   ```
   - 対象: TC-019

3. **[低優先度] CapabilityRegistry呼び出しの検証**
   - 問題: DP-5のgetByProjectExtended()呼び出しが直接検証されていない
   - 改善案: 結合テストでRegistry呼び出しを確認
   - 対象: 新規結合テスト追加（オプション）

### 必須改善

なし - 計画書は承認基準を満たしています。
