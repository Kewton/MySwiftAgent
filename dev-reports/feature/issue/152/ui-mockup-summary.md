## 📝 モックデータ

**ファイル**: `myAgentDesk/src/routes/(preview)/mockups/feature-152/data/mock.json`

**含まれるデータ**:
- `candidates`: 2つの要件候補（シンプル型 / 機能豊富型）
- `feedbackScores`: 4つのスコアタイプ
- `metrics`: 品質メトリクス（平均スコア、対話ターン数、完了率など）
- `diagnosticInfo`: 診断情報（会話履歴、プロンプト、LLMレスポンス）
- `promptVersions`: プロンプトバージョン（v1, v2）
- `abTestResults`: ABテスト結果（バージョンA vs バージョンB、統計的有意性）

## 📝 補足事項

### インタラクティブ機能

全てのパターンでインタラクティブな操作が可能:
- 候補カードのクリック選択
- フィードバックスライダーの操作
- タブ切り替え
- フォーム送信（モック）

### レスポンシブデザイン

全てのパターンがモバイル・タブレット・デスクトップに対応:
- モバイル（〜768px）: 1カラムレイアウト
- タブレット（768px〜1024px）: 2カラムレイアウト
- デスクトップ（1024px〜）: 3〜4カラムレイアウト

### モックデータの更新

モックデータを更新する場合:
1. `myAgentDesk/src/routes/(preview)/mockups/feature-152/data/mock.json` を編集
2. 開発サーバーがホットリロードで自動更新
