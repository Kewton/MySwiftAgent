# v1.36 タイムアウト問題 調査レポート

**Issue**: #305
**対象**: v1.36 Job Generation
**調査日**: 2025-12-25
**ステータス**: ✅ 対応完了（タイムアウト15分に延長）

---

## 1. 問題概要

v1.36 において、Job Generation が「Generation timed out (exceeded 10 minutes)」エラーで失敗した。

**エラーメッセージ**:
```
Generation Failed
Generation timed out (exceeded 10 minutes)
```

---

## 2. 根本原因サマリ

| 原因 | 影響 | 重要度 |
|------|------|--------|
| **fast_mode=False への変更** | LLM Evaluation が全タスクで実行される | 🔴 高 |
| **7タスク × 長時間処理** | 合計処理時間が10分超 | 🔴 高 |
| **フロントエンド10分タイムアウト** | 設定上限が600秒 | 🟡 中 |
| **並列実行の制限** | MAX_CONCURRENT_WORKFLOWS = 4 | 🟢 低 |

---

## 3. 詳細調査結果

### 3.1 フロントエンドタイムアウト設定

**ファイル**: `myAgentDesk/src/lib/types/job-version.ts` (lines 115-118)

```typescript
export const POLLING_CONFIG = {
    intervalMs: 1000,
    maxDurationMs: 600000 // 10 minutes
} as const;
```

**Issue #305** で5分から10分に延長済みだが、それでも不足。

---

### 3.2 Workflow Generation パイプライン（per-task処理時間）

**ファイル**: `workflowGeneratorAgents/agent.py`

| ノード | 処理内容 | 推定時間 |
|--------|----------|----------|
| `generator` | LLM でワークフローYAML生成 | 30-60秒 |
| `sample_input_generator` | LLM でサンプル入力生成 | 5-10秒 |
| `workflow_tester` | graphAiServer で実行テスト | 30-120秒 |
| `validator` | ルールベースバリデーション | 1-5秒 |
| `llm_evaluator` | **NEW: LLM 評価** | **10-30秒** |
| `result_summary_generator` | サマリ生成 | 1-5秒 |
| **合計（成功時）** | | **77-230秒** |

**注**: 失敗時は `self_repair` ループや `test_data_regenerator` が追加され、さらに処理時間が増加。

---

### 3.3 fast_mode=False の影響

**修正内容** (Issue #305):
- `state.py:140`: `fast_mode: bool = False`
- `agent.py:257`: `fast_mode: bool = False`

**fast_mode=True の場合**:
```
validator -> (is_valid && HTTP 200) -> result_summary_generator -> END
```
- LLM Evaluation をスキップ

**fast_mode=False の場合**:
```
validator -> llm_evaluator -> (routing) -> result_summary_generator -> END
```
- LLM Evaluation を必ず実行（+10-30秒/タスク）

---

### 3.4 並列実行の制限

**ファイル**: `jobTaskGeneratorAgents/nodes/workflow_generation.py` (line 27)

```python
MAX_CONCURRENT_WORKFLOWS = 4
```

- 7タスクの場合、4つが並列実行され、残り3つは待機
- 実質的に2バッチ処理（4 + 3）

---

### 3.5 v1.36 時間予測

**仮定**:
- 7タスク
- 1タスクあたり平均処理時間: 90秒（77-230秒の中央値）
- 並列実行: 4タスク同時

**計算**:
```
バッチ1: 4タスク × 90秒 = 90秒（並列）
バッチ2: 3タスク × 90秒 = 90秒（並列）
+ Task Breakdown フェーズ: ~60秒
+ Interface Definition フェーズ: ~60秒
+ オーバーヘッド: ~30秒
------------------------------------
合計: 約330秒 ≈ 5.5分
```

**実際には**:
- 一部タスクで self_repair ループ発生
- LLM API レートリミットによる遅延
- ネットワーク遅延
- graphAiServer 実行時間のばらつき

**結果**: 10分超

## 4. 原因の相関図

```
[Issue #305 品質重視修正]
     ↓

     ↓
```

## 7. 実施した対応

### タイムアウト時間を15分に延長

**修正ファイル**: `myAgentDesk/src/lib/types/job-version.ts`

```typescript
// Before
export const POLLING_CONFIG = {
    intervalMs: 1000,
    maxDurationMs: 600000 // 10 minutes
} as const;
export const TIMEOUT_ERROR_MESSAGE = 'Timeout: Job generation exceeded 10 minutes';

// After
export const POLLING_CONFIG = {
    intervalMs: 1000,
    maxDurationMs: 900000 // 15 minutes
} as const;
export const TIMEOUT_ERROR_MESSAGE = 'Timeout: Job generation exceeded 15 minutes';
```

---

## 8. 結論

v1.36 タイムアウトの**根本原因**は、Issue #305 の品質重視修正（`fast_mode=False`）により、全タスクで LLM Evaluation が実行されるようになったことである。

7タスクの処理時間が10分を超過し、フロントエンドのタイムアウト（600秒）に到達した。

**対応**: タイムアウトを15分（900秒）に延長。
