## 7. 改善提案

### 推奨改善（承認の場合も検討）

1. **[低優先度] TC-005の期待結果明確化**
   - 問題: 「エラーまたは0タスク検証発動」と若干曖昧
   - 改善案: LLM応答に依存するため、以下の2パターンを明記
     - パターンA: 0タスク検証発動 -> OrchestratorError
     - パターンB: LLMがタスクを生成 -> 正常終了（機能としては問題なし）
   - 影響: 軽微（テスト実行には支障なし）

2. **[低優先度] ログ確認コマンドのローカル対応追記**
   - 問題: TC-006のログ確認が`docker logs`のみ
   - 改善案: `--local-only`起動時のログ確認方法を追記
     ```bash
     # ローカル起動時のログ確認
     tail -f /path/to/expertAgent/logs/*.log | grep "capabilities="
     ```
   - 影響: 軽微（ハイブリッド起動時は標準出力で確認可能）

### 必須改善

なし
