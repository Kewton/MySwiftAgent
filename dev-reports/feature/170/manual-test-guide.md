# Issue #170 手動テストガイド

## 概要

MLOps UI Implementation (Issue #170) の手動ブラウザテストガイドです。
E2Eテストで検出できなかった動作や、UX/UIの品質を確認します。

---

## 1. テスト環境セットアップ

### 1.1 開発サーバー起動

```bash
cd myAgentDesk
npm run dev
```

サーバーが起動したら、ブラウザで以下にアクセス:
- **URL**: http://localhost:5173/mlops

### 1.2 推奨ブラウザ

| ブラウザ | バージョン | 優先度 |
|---------|----------|--------|
| Chrome | 最新版 | 必須 |
| Firefox | 最新版 | 推奨 |
| Safari | 最新版 | 推奨 |

### 1.3 テストデバイス

| デバイス | 解像度 | 確認内容 |
|---------|--------|---------|
| デスクトップ | 1280x720以上 | サイドバーナビゲーション |
| タブレット | 768x1024 | 2カラムレイアウト |
| モバイル | 375x667 | ボトムナビゲーション |

## 2. テストシナリオ

### シナリオ 1: ダッシュボード表示

**目的**: ダッシュボードの基本表示とリアルタイム機能の確認

**手順**:
1. `/mlops` にアクセス
2. ページタイトル「MLOps Dashboard」が表示されることを確認
3. 接続ステータス（Live/Offline）が表示されることを確認
4. 6つのメトリクスカードが表示されることを確認:
   - Average Score
   - Total Turns
   - Success Rate
   - Avg Latency
   - Total Sessions
   - Completion Rate
5. Model Usage Distributionチャートが表示されることを確認

**期待結果**:
- [ ] ページが正常にロードされる
- [ ] 全メトリクスカードが表示される
- [ ] 接続ステータスが表示される
- [ ] チャートが表示される

---

### シナリオ 2: 候補選択UI (重要)

**目的**: 候補カードの選択インタラクションの確認（E2Eで5件失敗した機能）

**手順**:
1. `/mlops/chat` にアクセス
2. 2つの候補カード（A, B）が表示されることを確認
3. カードAをクリック
4. カードAが選択状態（青枠、チェックマーク）になることを確認
5. カードBをクリック
6. カードBが選択状態になり、カードAの選択が解除されることを確認
7. 「決定」ボタンが有効になることを確認

**キーボード操作**:
1. カードAを選択した状態で、↓キーを押す
2. カードBが選択されることを確認
3. ↑キーを押す
4. カードAが選択されることを確認

**期待結果**:
- [ ] クリックで候補カードを選択できる
- [ ] 選択状態が視覚的に明確（青枠、チェックマーク）
- [ ] 複数選択はできない（1つのみ選択）
- [ ] キーボード（矢印キー）で選択を変更できる
- [ ] 「決定」ボタンが選択時のみ有効になる

---

### シナリオ 3: フィードバックフォーム

**目的**: フィードバックモーダルとスコアスライダーの確認

**手順**:
1. `/mlops/chat` にアクセス
2. 「フィードバック」ボタンをクリック
3. モーダルが開くことを確認
4. 4つのスコアスライダーが表示されることを確認:
   - Requirement Clarity
   - Interpretation Accuracy
   - Response Helpfulness
   - Overall Satisfaction
5. 各スライダーで1〜5のスコアを選択
6. コメント欄にテキストを入力
7. 「送信」ボタンをクリック

**モーダル操作**:
1. Escキーでモーダルを閉じる
2. Xボタンでモーダルを閉じる
3. キャンセルボタンでモーダルを閉じる

**期待結果**:
- [ ] モーダルが正常に開く
- [ ] 4つのスコアスライダーが表示される
- [ ] スコアを選択すると視覚的にフィードバックがある
- [ ] 送信ボタンはスコア選択後に有効になる
- [ ] Escキーでモーダルを閉じられる
- [ ] フォーカストラップが機能する（Tab連打でモーダル内を循環）

---

**期待結果**:
- [ ] 診断一覧が表示される
- [ ] フィルター機能が利用可能
- [ ] 選択した項目の詳細が表示される
- [ ] 会話タイムラインが日付でグループ化される
- [ ] User/Assistant のメッセージが視覚的に区別される
