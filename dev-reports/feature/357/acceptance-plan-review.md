## 6. 発見された問題点

### 重大な問題 (Critical): 0件

なし

### 警告 (Warning): 2件

#### W-001: TC-008のサンプルワークフロー検証がコメントアウト

**説明**: TC-008のBashコマンド内で、サンプルワークフローのバリデーション実行がコメント（`# Note: This may fail...`）で実行を避けている。

**影響**: JSON Schemaが実際のワークフローデータを正しくバリデーションできるかの検証が不完全。

**推奨対応**:
- サンプルワークフローをJSON Schema定義に合わせて修正
- `validator.validate(sample_workflow)` を実際に実行するコードを追加

**重要度**: 中

#### W-002: TC-006の実行コマンドが複数ディレクトリにまたがる

**説明**: TC-006のBashコマンドで、`cd expertAgent`, `cd graphAiServer`, `cd tests/contract` と複数回ディレクトリ移動が発生している。これは一つのコマンドブロックで実行すると失敗する可能性がある。

**影響**: テスト実行時に意図しないディレクトリで実行される可能性。

**推奨対応**:
- 各コマンドを絶対パスで実行するか、サブシェルで分離
- 例: `(cd expertAgent && uv run pytest tests/unit/ -v --tb=short)`

**重要度**: 低

### 情報 (Info): 1件

#### I-001: 手動検証項目の存在確認

**説明**: Issue #357には手動検証項目（運用検証、スキーマバージョニング戦略の文書化）が含まれている。これらは自動テストの対象外として正しく分類されている。

**コメント**: 受入テスト計画書のセクション9「補足事項」に手動検証項目が明記されており、適切に管理されている。
