#### スキル分割の詳細

**旧: 作業計画スキル（`/plan`）**
- Feature全体のIssue分割とスケジュール立案を1つに統合
- 責任範囲が広すぎた（単一責任原則違反）

**新: 2つのスキルに分離**

##### 1. Issue分割スキル（`/issue-split`）
- **目的**: FeatureをIssueに分割
- **モデル**: Opus
- **フェーズ**: 4. Issue分割（メインセッション）
- **責任範囲**:
  - 縦割り（Vertical Slice）でのIssue分割
  - 依存関係マトリクス作成
  - Issue サイズ見積もり
  - マイルストーン計画
  - リソース配分

##### 2. 作業計画スキル（`/plan`）
- **目的**: Issue単位の具体的な作業計画立案
- **モデル**: Opus
- **フェーズ**: 5. 作業計画（メインセッション）
- **責任範囲**:
  - Issue内の詳細タスク分解
  - タスク依存関係整理
  - 日次スケジュール作成
  - チェックポイント設定
  - 成果物チェックリスト

## 📝 使用例

### Feature開始からIssue着手まで

```bash
# メインセッション（developブランチ）

# 1. 要件定義
/requirements ユーザー管理機能

# 2. 設計方針
/design ユーザー管理システムの設計

# 3. レビュー
/review-arch [設計書]

# 4. Issue分割（新スキル）
/issue-split ユーザー管理機能
# → Issue #201, #202, #203に分割される

# 5. Issue単位の作業計画（更新されたスキル）
/plan Issue #201
# → Issue #201の詳細タスク、日次計画が生成される

# 🔄 セッション切替
git worktree add ../MySwiftAgent-worktrees/issue-201 -b issue/201-user-profile
cd ../MySwiftAgent-worktrees/issue-201

# worktreeセッション（issueブランチ）
# 開発実装...
/progress  # 進捗報告
/refactor  # リファクタリング（必要時）

# PR作成、マージ後
cd ~/MySwiftAgent  # メインセッションに戻る

# フィーチャーフラグ設定、Wiki文書化...
```
